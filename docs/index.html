TraceRoot

Trace a Python error back to its root cause, with fewer agent tokens. A coding agent runs traceroot on a failing command and gets a ~60-token ranked answer, instead of reading the traceback and several files.

How it works

Two models, each with one small job. Plain Python does everything else and checks everything they return.

Jev (TypeSafe AI): decides

A cheap gate: is this a simple error whose fix is on the crash line? If yes (p ≥ 0.8), TraceRoot answers immediately and Claude is never called. Otherwise Jev gives a second opinion on Claude's candidates.

Claude (Haiku): generates

3–6 candidate root causes as strict JSON, from the traceback, the crash windows, and the definitions the failing code uses. It never sees whole files.

Plain Python: checks

Parses tracebacks and reads only safe project files (never .env or keys). It follows functions, constants, and methods even after they've returned, validates every file:line, ranks the causes, and saves them so traceroot next is free.

What the agent sees

$ traceroot analyze --run "python main.py"
[1/4] none_value (claude=0.60, Jev agrees) tests/fixtures/medium_none_cart.py:5
cause: load_cart replaces empty item list with None
fix: Keep items as an empty list (for example, default to [] instead of None) rather than converting falsy values to None.
more: `traceroot next`

The crash is in price_items (line 11), three calls away. The bug is in load_cart (line 5), which isn't in the traceback at all.

Honest limits

  • Complex errors on small projects cost ~8% more model tokens than sending everything, with one fewer correct answer (29/36 vs. 30/36).
  • In one end-to-end agent trial (headless Claude Code, 170-line project), the agent found and used TraceRoot on its own, but used more total tokens (246k vs. 207k), because extra agent turns cost more than the file reading saved.
  • 54 cases, each run once, written by the same model family the tool uses. Only the 9 held-out cases were never tuned on.
  • Code context is for Python tracebacks only, so far.

Use it with your agent

pipx install git+https://github.com/SZBro/traceroot.git
mkdir -p ~/.traceroot && echo "TYPESAFE_API_KEY=your-key" >> ~/.traceroot/.env
traceroot install-skill     # Claude Code skill for all your projects
traceroot check             # verify the setup

Needs Python 3.10+ and Claude Code installed and logged in. Full steps, including other agents (Codex, Cursor, Copilot), are in the README.

TraceRoot was built for TCSS 490, Artifact 3 ("AI Inside It"). All numbers come from bench/versions/v6_results.jsonl, and you can regenerate them with python bench/run_bench.py. Token counts for model calls come from the APIs. Agent-context tokens are len(text) // 4 estimates.
