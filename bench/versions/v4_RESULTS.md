# TraceRoot benchmark results

36 mutation cases across 4 projects (gradebook, logs, planner, shop). Generated by `bench/run_bench.py`; a hit = right file, line within +/-1 of the mutated line.

## Accuracy and model cost

| Method | Top-1 | Top-3 | Found at all | Avg model tokens / case | Avg latency |
|---|---|---|---|---|---|
| TraceRoot, all (36) | 30/36 (83%) | 33/36 (92%) | 33/36 (92%) | 8,595 | 7.9 s |
| Baseline: Claude + full files, all (36) | 32/36 (89%) | 35/36 (97%) | 35/36 (97%) | 8,807 | 8.9 s |
| TraceRoot, dev set (tuned on) (27) | 22/27 (81%) | 25/27 (93%) | 25/27 (93%) | 8,316 | 8.0 s |
| Baseline: Claude + full files, dev set (tuned on) (27) | 24/27 (89%) | 27/27 (100%) | 27/27 (100%) | 8,870 | 8.7 s |
| TraceRoot, **held-out set** (9) | 8/9 (89%) | 8/9 (89%) | 8/9 (89%) | 9,431 | 7.6 s |
| Baseline: Claude + full files, **held-out set** (9) | 8/9 (89%) | 8/9 (89%) | 8/9 (89%) | 8,617 | 9.5 s |

TraceRoot used **2% fewer model tokens** per case than the full-file baseline.

## Simple errors vs. complex errors

Split by the path TraceRoot took: **simple** = the Jev gate answered alone; **complex** = Claude + Jev.
"Agent context" = tokens the calling agent must read: the traceback + files it references (baseline) vs. TraceRoot's compact answer.

| Errors | Cases | TraceRoot top-1 | Baseline top-1 | TraceRoot model tokens | Baseline model tokens | Model-token change | Agent context: baseline -> TraceRoot |
|---|---|---|---|---|---|---|---|
| simple (gate) | 11 | 11/11 (100%) | 11/11 (100%) | 2,966 | 8,412 | -65% | 2,100 -> 52 (-98%) |
| complex (full) | 25 | 19/25 (76%) | 21/25 (84%) | 11,072 | 8,981 | +23% | 1,735 -> 59 (-97%) |
| all | 36 | 30/36 (83%) | 32/36 (89%) | 8,595 | 8,807 | -2% | 1,846 -> 57 (-97%) |

## Does Jev's re-ranking help? (full-path cases only)

Same TraceRoot candidates, two orderings: **Jev score** (what TraceRoot ships) top-1 19/25 (76%) vs. **Claude's own rank** top-1 21/25 (84%).

## Tokens the calling agent reads

| | Avg tokens / case |
|---|---|
| Traceback + full files in the traceback | 1,846 |
| Traceback + every project source file | 2,548 |
| TraceRoot compact output (top cause) | 57 |

Average reduction: **96%** vs. reading the traceback's files, **98%** vs. reading the whole project. (Text tokens are len//4 estimates.)
