# TraceRoot benchmark results

45 mutation cases across 5 projects (gradebook, library, logs, planner, shop). Generated by `bench/run_bench.py`; a hit = right file, line within +/-1 of the mutated line.

## Accuracy and model cost

| Method | Top-1 | Top-3 | Found at all | Avg model tokens / case | Avg latency |
|---|---|---|---|---|---|
| TraceRoot, all (45) | 37/45 (82%) | 38/45 (84%) | 38/45 (84%) | 7,143 | 7.8 s |
| Baseline: Claude + full files, all (45) | 41/45 (91%) | 44/45 (98%) | 44/45 (98%) | 8,711 | 9.1 s |
| TraceRoot, dev set (tuned on) (36) | 31/36 (86%) | 32/36 (89%) | 32/36 (89%) | 7,255 | 8.0 s |
| Baseline: Claude + full files, dev set (tuned on) (36) | 32/36 (89%) | 35/36 (97%) | 35/36 (97%) | 8,807 | 8.9 s |
| TraceRoot, **held-out set** (9) | 6/9 (67%) | 6/9 (67%) | 6/9 (67%) | 6,693 | 6.9 s |
| Baseline: Claude + full files, **held-out set** (9) | 9/9 (100%) | 9/9 (100%) | 9/9 (100%) | 8,327 | 10.1 s |

TraceRoot used **18% fewer model tokens** per case than the full-file baseline.

## Simple errors vs. complex errors

Split by the path TraceRoot took: **simple** = the Jev gate answered alone; **complex** = Claude + Jev.
"Agent context" = tokens the calling agent must read: the traceback + files it references (baseline) vs. TraceRoot's compact answer.

| Errors | Cases | TraceRoot top-1 | Baseline top-1 | TraceRoot model tokens | Baseline model tokens | Model-token change | Agent context: baseline -> TraceRoot |
|---|---|---|---|---|---|---|---|
| simple (gate) | 15 | 15/15 (100%) | 15/15 (100%) | 2,019 | 8,309 | -76% | 2,051 -> 51 (-98%) |
| complex (full) | 30 | 22/30 (73%) | 26/30 (87%) | 9,705 | 8,912 | +9% | 1,736 -> 65 (-96%) |
| all | 45 | 37/45 (82%) | 41/45 (91%) | 7,143 | 8,711 | -18% | 1,841 -> 61 (-97%) |

## Does Jev's re-ranking help? (full-path cases only)

Same TraceRoot candidates, two orderings: **Jev score** top-1 18/30 (60%) vs. **Claude's own rank** top-1 22/30 (73%). (These runs shipped: claude order.)

## Tokens the calling agent reads

| | Avg tokens / case |
|---|---|
| Traceback + full files in the traceback | 1,841 |
| Traceback + every project source file | 2,529 |
| TraceRoot compact output (top cause) | 61 |

Average reduction: **96%** vs. reading the traceback's files, **97%** vs. reading the whole project. (Text tokens are len//4 estimates.)

- Gate precision (gate answers that were right): 15/15 (100%)
