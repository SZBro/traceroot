# TraceRoot benchmark results

54 mutation cases across 6 projects (bank, gradebook, library, logs, planner, shop). Generated by `bench/run_bench.py`; a hit = right file, line within +/-1 of the mutated line.

## Accuracy and model cost

| Method | Top-1 | Top-3 | Found at all | Avg model tokens / case | Avg latency |
|---|---|---|---|---|---|
| TraceRoot, all (54) | 47/54 (87%) | 51/54 (94%) | 51/54 (94%) | 7,040 | 7.6 s |
| Baseline: Claude + full files, all (54) | 47/54 (87%) | 52/54 (96%) | 52/54 (96%) | 8,621 | 9.3 s |
| TraceRoot, dev set (tuned on) (45) | 41/45 (91%) | 42/45 (93%) | 42/45 (93%) | 7,135 | 7.6 s |
| Baseline: Claude + full files, dev set (tuned on) (45) | 41/45 (91%) | 44/45 (98%) | 44/45 (98%) | 8,711 | 9.1 s |
| TraceRoot, **held-out set** (9) | 6/9 (67%) | 9/9 (100%) | 9/9 (100%) | 6,568 | 7.8 s |
| Baseline: Claude + full files, **held-out set** (9) | 6/9 (67%) | 8/9 (89%) | 8/9 (89%) | 8,171 | 10.0 s |

TraceRoot used **18% fewer model tokens** per case than the full-file baseline.

## Simple errors vs. complex errors

Split by the path TraceRoot took: **simple** = the Jev gate answered alone; **complex** = Claude + Jev.
"Agent context" = tokens the calling agent must read: the traceback + files it references (baseline) vs. TraceRoot's compact answer.

| Errors | Cases | TraceRoot top-1 | Baseline top-1 | TraceRoot model tokens | Baseline model tokens | Model-token change | Agent context: baseline -> TraceRoot |
|---|---|---|---|---|---|---|---|
| simple (gate) | 18 | 18/18 (100%) | 17/18 (94%) | 1,968 | 8,202 | -76% | 1,922 -> 51 (-97%) |
| complex (full) | 36 | 29/36 (81%) | 30/36 (83%) | 9,577 | 8,830 | +8% | 1,719 -> 68 (-96%) |
| all | 54 | 47/54 (87%) | 47/54 (87%) | 7,040 | 8,621 | -18% | 1,787 -> 62 (-97%) |

## Does Jev's re-ranking help? (full-path cases only)

Same TraceRoot candidates, two orderings: **Jev score** top-1 28/36 (78%) vs. **Claude's own rank** top-1 29/36 (81%). (These runs shipped: claude order.)

## Tokens the calling agent reads

| | Avg tokens / case |
|---|---|
| Traceback + full files in the traceback | 1,787 |
| Traceback + every project source file | 2,485 |
| TraceRoot compact output (top cause) | 62 |

Average reduction: **96%** vs. reading the traceback's files, **97%** vs. reading the whole project. (Text tokens are len//4 estimates.)
